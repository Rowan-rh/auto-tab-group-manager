# tab-jump Delta Spec

## Purpose

让扩展弹窗的标签组树从"只读视图 + 关闭操作"升级为标签页导航器：点击任一标签页条目即可跳转激活该标签页。

## ADDED Requirements

### Requirement: 点击跳转标签页
弹窗标签组树中的每个标签页条目 SHALL 可点击；点击后系统 MUST 激活该标签页，并聚焦该标签页所在的浏览器窗口（跨窗口时切换焦点），随后关闭弹窗。

#### Scenario: 跳转当前窗口的标签页
- **WHEN** 用户在弹窗中点击当前窗口某个组内的标签页条目
- **THEN** 该标签页被激活，弹窗关闭

#### Scenario: 跳转其他窗口的标签页
- **WHEN** 用户点击的标签页位于另一个浏览器窗口
- **THEN** 目标窗口获得焦点且该标签页被激活

#### Scenario: 点击关闭按钮不触发跳转
- **WHEN** 用户点击标签页条目右侧的关闭按钮
- **THEN** 仅关闭该标签页，不发生跳转，标签组列表刷新
