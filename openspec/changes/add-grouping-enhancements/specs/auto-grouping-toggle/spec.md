# auto-grouping-toggle Delta Spec

## Purpose

提供自动分组的总开关，允许用户临时暂停扩展的自动分组行为而不必禁用整个扩展，同时保留手动整理能力。

## ADDED Requirements

### Requirement: 自动分组总开关
系统 SHALL 在扩展弹窗中提供"自动分组"开关，其状态 MUST 持久化保存；开关状态 MUST NOT 影响手动"重新整理所有标签页"与"排序标签页"操作。

#### Scenario: 关闭开关后不再自动分组
- **WHEN** 用户关闭"自动分组"开关后新建或刷新同域名的多个标签页
- **THEN** 这些标签页不被自动归组，且配置在扩展重启后仍保持关闭状态

#### Scenario: 开关不影响手动操作
- **WHEN** "自动分组"开关处于关闭状态，用户点击"重新整理所有标签页"
- **THEN** 手动整理正常执行并完成分组

#### Scenario: 重新开启后恢复自动分组
- **WHEN** 用户重新打开"自动分组"开关
- **THEN** 后续标签页事件重新触发自动分组，存量未分组标签页在下一次事件或手动整理时归组
