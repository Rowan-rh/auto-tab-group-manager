- [x] 1.1 `manifest.json` 的 permissions 增加 `storage`
- [x] 1.2 定义映射数据的存储结构（`chrome.storage.sync` 中的 `domainMappings`，形如 `[{ domain, label }]`），约定读写入口

## 2. 弹窗配置 UI

- [x] 2.1 `popup.html` 新增"域名映射"配置区：已有规则列表（域名 → 标签名 + 删除按钮）、添加表单（域名输入框、标签名输入框、添加按钮）、非法输入提示
- [x] 2.2 `popup.js` 实现规则列表加载、添加（含空值与域名格式校验、重复域名覆盖）、删除逻辑，全部持久化到 `chrome.storage.sync`

## 3. 分组逻辑改造

- [x] 3.1 `background.js`：新增映射解析函数（域名 → 标签名，未命中返回域名本身），`groupTab` 的组标题解析、已有组匹配、同域名标签页统计均改为基于解析后的标题
- [x] 3.2 `popup.js`："重新整理所有标签页"逻辑同样基于映射解析后的标题分组
- [x] 3.3 验证域名变更时的组归属校正逻辑在映射生效后仍正确（原组标题与解析后标题不一致时移出重归）

## 4. 策略导出/导入

- [x] 4.1 `popup.html` 在域名映射配置区增加"导出"与"导入"按钮及隐藏的文件选择器
- [x] 4.2 `popup.js` 实现导出：序列化全部规则为 JSON（`{ version, domainMappings }` 结构）并触发文件下载
- [x] 4.3 `popup.js` 实现导入：读取并校验 JSON（整体结构非法则拒绝），过滤非法条目，合法条目与现有规则合并（同名域名覆盖）后持久化，提示实际导入条目数

## 4b. 多窗口与颜色优化

- [x] 4b.1 `background.js`：查组、统计同标题标签页、建组均限定在标签页所在窗口（`windowId`），消除跨窗口归组报错
- [x] 4b.2 `popup.js`："重新整理"按窗口分片处理，每个窗口内独立建组/归组
- [x] 4b.3 组颜色改为由标题确定性派生（哈希取色），替换随机颜色，保证同名组颜色稳定
