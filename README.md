# Auto Tab Group Manager

一个 Chrome 浏览器扩展（Manifest V3），自动按域名整理标签页，并提供自定义组名、标签排序、标签组管理和闲置标签页处理。你可以设置“域名 → 组名”映射，让来自不同域名的标签页归入同一组，也可以在管理页展开、排序、解散或关闭标签组。

## 安装

### 1. 克隆代码仓库

```bash
git clone https://github.com/Rowan-rh/auto-tab-group-manager.git
```

### 2. 打开扩展管理页

在 Chrome 地址栏直接粘贴 `chrome://extensions/` 并回车（无需从设置菜单进入）。

### 3. 开启开发者模式

打开页面右上角的"开发者模式"开关：

## 功能速览

- **自动分组**：标签页加载、创建、移动时自动按域名归组，同域名标签页 ≥ 2 个即成组
- **域名映射**：可将域名映射为自定义标签名（如 `code.alibaba-inc.com → 阿里 Code`），命中映射的域名按标签名归组，未命中的按域名归组
- **多域名同组**：多个域名可映射到同一个标签名，归入同一个组
- **多窗口独立**：每个浏览器窗口独立分组，互不干扰
- **颜色稳定**：组颜色由标题确定性派生，同名组重建后颜色保持一致
- **手动整理**：一键重新整理所有标签页 / 一键关闭所有分组
- **弹窗管理**：树状展示当前所有标签组及其标签页，支持单独关闭组或标签页
- **策略导入导出**：映射规则可导出为 JSON 文件备份，也可从 JSON 导入合并（非法文件拒绝、非法条目过滤）

## 使用说明

### 域名映射

在弹窗"域名映射"区填写域名与标签名，点击"添加映射"：

- 域名需为合法主机名格式（如 `code.alibaba-inc.com`），标签名不能为空
- 重复添加同一域名时，新标签名覆盖旧标签名
- 每条规则可单独删除，删除后该域名恢复按域名分组

![弹窗主界面：整理按钮、域名映射表单与规则列表](%E6%8F%92%E4%BB%B6%E6%88%AA%E5%9B%BE/PixPin_2026-08-21_16-15-31.png)

### 导入 / 导出

- **导出**：将全部映射规则下载为 JSON 文件，格式如下：

```json
{
  "version": 1,
  "domainMappings": [
    { "domain": "code.alibaba-inc.com", "label": "阿里 Code" },
    { "domain": "gitlab.example.com", "label": "阿里 Code" }
  ]
}
```

- **导入**：选择 JSON 文件，合法条目与现有规则合并（同名域名覆盖），非法条目被过滤并提示实际导入条数；整体结构非法的文件会被拒绝，现有规则不受影响

![点击导出按钮下载 domain-mappings-*.json 文件](%E6%8F%92%E4%BB%B6%E6%88%AA%E5%9B%BE/PixPin_2026-08-21_16-16-34.png)

### 标签组管理

- **重新整理所有标签页**：按映射/域名规则对全部窗口的标签页重新分组
- **关闭所有标签页分组**：解散全部标签组
- 标签组列表支持单独关闭某个组或某个标签页

## 项目结构

| 文件 | 职责 |
|------|------|
| `manifest.json` | 扩展元信息与权限（`tabs`、`tabGroups`、`storage`） |
| `background.js` | 后台服务：监听标签页事件，自动分组与映射解析 |
| `popup.html` / `popup.js` | 弹窗 UI：整理/解散分组、映射配置、导入导出、标签组树 |
| `AGENT.md` | 开发规范与约束（Git 分支规范、代码规范、PR 检查清单） |
| `openspec/` | OpenSpec 规范与变更记录 |

## 开发

- 开发规范见 [AGENT.md](./AGENT.md)：分支前缀（`feat/`、`fix/`、`docs/` 等）、提交信息格式（`<类型>: <中文说明>`）、`main`/`develop` 保护分支需走 MR
- 行为变更走 OpenSpec 流程：`openspec/changes/<change-name>/` 下维护 proposal、spec delta 与 tasks，验证通过后 `openspec archive` 归档
- 提交前请运行 `node --check background.js && node --check popup.js` 与 `openspec validate <change-name> --strict`

## 已知限制

- 特殊页面（`chrome://`、`about:` 等非 http 页面）不参与分组
- 同窗口内同标题标签页不足 2 个时不创建组
- 用户拖动标签页期间 Chrome 会临时锁定标签编辑，扩展会自动重试，长时间拖动时本次分组会跳过并在下次事件触发时补上
