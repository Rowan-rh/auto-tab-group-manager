# Auto Tab Group Manager

一个 Chrome 浏览器扩展（Manifest V3），按域名自动整理标签页，并提供自定义映射、闲置折叠、休眠标签处理和批量管理。默认按主域名分组，也可改为完整域名；不同域名还可以通过映射合并到同一标签组。

## 安装

### 1. 克隆代码仓库

```bash
git clone https://github.com/Rowan-rh/auto-tab-group-manager.git
```

### 2. 打开扩展管理页

在 Chrome 地址栏直接粘贴 `chrome://extensions/` 并回车（无需从设置菜单进入）。

## 功能速览

- **自动分组**：标签页加载、创建、移动时按域名和映射规则归组；同一窗口内解析为相同组名的标签页至少两个时才创建标签组
- **分组粒度可选**：默认按主域名归组（如 `www.example.com` 与 `docs.example.com` 都归入 `example.com`），也可按完整域名分别分组
- **精确与通配符映射**：支持 `code.example.com → 代码`，也支持 `*.example.com → 项目`；精确规则优先，多条通配符同时命中时选择更具体的一条
- **多域名同组**：同一窗口内多个不同域名可映射到同一个组名
- **闲置自动折叠**：标签组在指定分钟内没有活动时自动折叠；默认开启，阈值默认为 30 分钟
- **休眠标签页清理**：可启用管理页按闲置阈值批量关闭的操作入口（默认关闭，阈值默认 60 分钟）；也可用独立的手动阈值执行一次性清理
- **多窗口独立**：每个浏览器窗口独立分组，互不干扰
- **颜色稳定**：组颜色由标题确定性派生，同名组重建后颜色保持一致
- **整理与排序**：一键按当前分组规则整理所有窗口；标签页和标签组可按标题排序
- **弹窗管理**：树状查看标签组和组内标签页，可切换到指定标签页、解散单个组或关闭单个标签页
- **标签组管理页**：按窗口查看标签组，支持全局或单组展开、折叠、排序、解散；也可关闭休眠标签页或关闭整组标签页
- **活动信息**：管理页展示标签页地址路径与最近活动时间，便于识别长时间未使用的页面
- **策略导入导出**：映射规则可导出为 JSON 文件备份，也可从 JSON 导入合并（非法文件拒绝、非法条目过滤）

## 使用说明

### 自动分组与分组方式

- “自动分组”开关控制新建、加载或移动标签页时是否自动归组。
- “域名分组方式”提供两种选择：
  - **按主域名**（默认）：例如 `www.example.co.uk` 按 `example.co.uk` 分组。
  - **按完整域名**：例如 `www.example.com` 和 `docs.example.com` 分别成组。
- 更改分组方式后，点击“重新整理所有标签页”即可将设置应用到已有标签页。

### 域名映射

在弹窗“域名映射”区填写域名规则和组名，点击“添加映射”：

- 精确规则示例：`code.example.com → 代码`。
- 通配符规则示例：`*.example.com → 项目`，可匹配子域名，不匹配 `example.com` 本身。
- 多个域名可以使用同一个组名；精确规则覆盖通配符规则，多条通配符同时命中时最长后缀优先。
- 域名需为合法主机名或 `*.suffix` 格式，组名不能为空；重复添加同一规则时，新组名覆盖旧组名。
- 每条规则可单独删除，删除后对应域名恢复按当前分组方式归组。

### 闲置折叠与休眠标签页清理

- **无活动自动折叠**：默认开启，默认阈值为 30 分钟。后台每分钟检查一次；组内所有标签页都超过阈值后才会折叠该组，当前聚焦窗口中含活动标签页的组会跳过本轮检查。修改分钟数后点击“保存”；需要时可关闭此功能。
- **按预设阈值清理**：默认关闭，默认阈值为 60 分钟。开启弹窗中的“自动关闭休眠”后，管理页的全局和组级“关闭休眠”按钮可按该阈值清理标签页；点击后会显示待关闭页面并要求确认。
- **手动阈值清理**：在标签组管理页输入分钟数并点击“关闭 >N 分钟未活动”，即可按本次输入的阈值清理。此入口不依赖弹窗中的“自动关闭休眠”开关。执行前会显示待关闭页面并要求确认。

### 标签组管理页

从弹窗点击“标签组管理”打开独立管理页。页面按浏览器窗口列出已分组的标签组、组内标签页、折叠状态和最近活动信息；未分组的标签页不显示，也不参与管理页操作。全局工具栏可展开/折叠所有组、排序、解散所有分组、关闭休眠标签页或关闭所有已分组标签页；每个组也提供对应的组级操作。

- **排序**会按组标题和标签页标题重新排列，不会把未分组的标签页纳入排序。
- **解散分组**只移除组关系，不关闭标签页；**全部关闭标签页**会关闭所有已分组标签页。
- 关闭休眠或关闭标签页前会先展示确认对话框；休眠操作只关闭符合闲置阈值的标签页。
- 页面展示 URL 路径预览（最长 48 个字符）和距离最近活动的时间；悬停可查看完整 URL 与活动时间。

### 导入 / 导出

- **导出**：将全部映射规则下载为 JSON 文件，格式如下：

```json
{
  "version": 1,
  "domainMappings": [
    { "domain": "code.example.com", "label": "代码" },
    { "domain": "docs.example.com", "label": "文档" }
  ]
}
```

- **导入**：选择 JSON 文件，合法条目与现有规则合并（同名域名覆盖），非法条目被过滤并提示实际导入条数；整体结构非法的文件会被拒绝，现有规则不受影响

### 弹窗快捷操作

- **重新整理所有标签页**：按映射/域名规则对全部窗口的标签页重新分组
- **排序标签页**：按标题整理分组标签页
- **关闭所有标签页分组**：解散全部标签组，保留标签页
- 弹窗下方的树状列表支持切换标签页、解散单个组或关闭单个标签页

## 项目结构

| 文件 | 职责 |
|------|------|
| `manifest.json` | 扩展元信息与权限（`tabs`、`tabGroups`、`storage`） |
| `common.js` | 后台、弹窗与管理页共享的域名解析、排序、休眠判断和重试工具 |
| `background.js` | 后台服务：监听标签页事件、自动分组、记录活动时间并折叠闲置分组 |
| `popup.html` / `popup.js` | 弹窗设置：分组方式、映射规则、导入导出、整理与标签组树 |
| `manager.html` / `manager.js` | 独立管理页：按窗口管理已分组标签页，提供排序、折叠/展开、解散及休眠清理 |
| `test/` | 共享规则、分组可靠性和映射存储相关的自动化测试 |
| `AGENT.md` | 开发规范与约束（Git 分支规范、代码规范、PR 检查清单） |
| `openspec/` | OpenSpec 规范与变更记录 |

## 开发

- 开发规范见 [AGENT.md](./AGENT.md)：分支前缀（`feat/`、`fix/`、`docs/` 等）、提交信息格式（`<类型>: <中文说明>`）、`main`/`develop` 保护分支需走 MR
- 行为变更走 OpenSpec 流程：`openspec/changes/<change-name>/` 下维护 proposal、spec delta 与 tasks，验证通过后 `openspec archive` 归档
- 提交前请运行 `node --check background.js && node --check popup.js` 与 `openspec validate <change-name> --strict`

## 已知限制

- 特殊页面（`chrome://`、`about:` 等非 http 页面）不参与分组
- 同一窗口内解析为相同组名的标签页不足 2 个时不创建组
- 用户拖动标签页期间 Chrome 会临时锁定标签编辑，扩展会自动重试，长时间拖动时本次分组会跳过并在下次事件触发时补上
